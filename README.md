# FileMoon

FileMoon is a full-stack file management and sharing platform built using Node.js, Express.js, MongoDB, and JavaScript.

## Features

- User Signup and Login
- User Authentication
- File Upload
- File Download
- File Sharing
- Email Notifications using Nodemailer
- File Management
- MongoDB Database Integration

## Tech Stack

- JavaScript
- Node.js
- Express.js
- MongoDB
- Nodemailer
